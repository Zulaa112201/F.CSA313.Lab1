 **XPath зайлсхийх**
 XPath нь веб хуудасны бүтцээс (HTML DOM) хэт их хамааралтай байдаг тул хөгжүүлэгч UI дээр жижиг өөрчлөлт хийхэд л тест шууд унадаг тул хэрэглэхэд бага зэрэг хүндрэлтэй. Үүний оронд Playwright-ийн `getByRole`, `getByPlaceholder`, `getByText` зэрэг хэрэглэгчийн харж, харилцаж буй өнцгөөс ханддаг locator-уудыг ашиглах нь кодыг уншихад ойлгомжтой бөгөөд найдвартай ажиллагааг хангадаг юм шиг санагдсан.

 
* **Codegen болон өөрийн кодын ялгаа:**
 Playwright-ийн автоматаар бичигч (codegen) нь үйлдэл бүрийг алгасахгүй бичдэг хэдий ч зарим үед хэт нарийн, урт CSS selector эсвэл шаардлагагүй хүлээлтүүдийг үүсгээд байсан. Харин өөрөө бичсэн код маань илүү цэгцтэй, илүү товчхон болсон бөгөөд зөвхөн хэрэгтэй элементүүдээ `getByRole` ашиглан барьж авснаар засвар үйлчилгээ хийхэд илүү хялбар болсон.


**Selenium ялгаа**
Selenium бол хуучинсаг, маш олон жилийн түүхтэй хэрэгсэл учраас олон хэл дээр ажилладаг давуу талтай ч тохиргоо хийх, драйверуудаа холбох гээд бага зэрэг төвөгтэй байдаг. Харин Playwright нь гарч ирээд удаагүй байгаа ч гэсэн хамаагүй хурдан, дээрээс нь Chromium, Firefox, WebKit гээд бүх браузерыг шууд дэмждэг нь гоё санагдсан. Бас тест унахад шууд trace файл үүсгээд, хаанаа алдаа гарсныг яг видео шиг харж болдог болохоор алдаа олох, дебаг хийхэд Selenium-ээс хамаагүй амар юм билээ.
