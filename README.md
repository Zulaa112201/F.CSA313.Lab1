\# F.CSA313 - Лаборатори №1: UI автомат тест (Playwright)



\## Ажлын зорилго

Энэхүү лабораторийн ажлаар орчин үеийн UI автоматжуулалтын хэрэгсэл болох Playwright-ийн тусламжтайгаар веб програмын функционал тестийг автоматжуулах дадлага хийлээ. Saucedemo демо цахим худалдааны сайтыг ашиглан нэвтрэх үйлдэл, сөрөг тест болон сагсанд бараа нэмэх үйлдэл зэрэг үндсэн тестүүдийг амжилттай хэрэгжүүлсэн\[cite: 1].



\## Гүйцэтгэсэн тестүүд

1\. \*\*Амжилттай нэвтрэх тест\*\*: Зөв хэрэглэгчийн нэр, нууц үгээр нэвтэрч бүтээгдэхүүний хуудас амжилттай гарч ирж буйг шалгасан\[cite: 1].

2\. \*\*Амжилтгүй нэвтрэх сөрөг тест\*\*: Буруу нууц үг оруулахад систем алдааны мессеж зөв харуулж буйг баталгаажуулсан\[cite: 1].

3\. \*\*Бараа сагслах тест\*\*: Нэвтэрсний дараа барааны "Add to cart" товчийг дарж сагсны тоолуурын утга өөрчлөгдөж буйг шалгасан\[cite: 1].



\## Playwright болон Selenium-ийн харьцуулсан ажиглалт

Selenium болон Playwright хоёулаа Apache 2.0 нээлттэй эхийн лицензтэй тул үнэ төлбөргүй ашиглах боломжтой юм\[cite: 1]. Гэхдээ техникийн хувьд Playwright нь хөгжүүлэгчид илүү ээлтэй, орчин үеийн шийдлүүдийг санал болгодог болох нь анзаарагдсан\[cite: 1]. Тухайлбал, Selenium дээрэлемент бэлэн болохыг хүлээхийн тулд гараар explicit wait бичих шаардлагатай байдаг бол Playwright нь автоматаар хүлээдэг (auto-wait) функцтэй тул тест илүү тогтвортой ажиллана\[cite: 1]. Мөн Selenium шиг тусдаа хөтчийн драйверуудыг гараар татаж суулгах шаардлагагүйгээр нэг командаар бүх хөтөч суух нь маш хялбар юм\[cite: 1]. Codegen хэрэгсэл болон Trace Viewer ашиглан алхам бүрийн бичлэг, DOM snapshot харж дебаг хийх боломжтой нь алдааг олоход маш дөхөм байлаа\[cite: 1]. Ерөнхийдөө Playwright нь хурд, тохиргооны хялбар байдал болон хэрэглэгчийн туршлагаараа илүү давуу талтай болох нь харагдсан\[cite: 1].
