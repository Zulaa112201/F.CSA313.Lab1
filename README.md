\# F.CSA313 - Лабораторийн ажил №1



Энэхүү лабораторийн ажлаар Microsoft-ын хөгжүүлж буй орчин үеийн Playwright хэрэгслийг ашиглан веб програмын автомат тест хэрхэн бичих талаар суралцаж туршиж үзлээ\[cite: 1]. Дадлагын хүрээнд алдартай демо дэлгүүр болох Saucedemo сайт дээр суурилан хэрэглэгч нэвтрэх, буруу утга оруулахад алдаа заах, мөн сагсанд бараа нэмэх зэрэг үндсэн функционал тестүүдийг амжилттай бичсэн юм\[cite: 1].



\## Туршиж гүйцэтгэсэн тестүүд

\* \*\*Амжилттай нэвтрэх:\*\* Системд стандарт эрхээр нэвтэрсний дараа хэрэглэгчийн үндсэн бүтээгдэхүүний хуудас амжилттай ачаалж байгаа эсэхийг шалгасан\[cite: 1].

\* \*\*Сөрөг тест (Амжилтгүй нэвтрэх):\*\* Нууц үгээ андуурч эсвэл буруу оруулахад систем ямар нэгэн байдлаар алдааны мэдэгдэл зөв гаргаж буйг баталгаажуулсан\[cite: 1].

\* \*\*Бараа сагслах үйлдэл:\*\* Нэвтэрсний дараа дурын барааны "Add to cart" товчийг дарахад дэлгэц дээрх сагсны тоолуур өөрчлөгдөж байгаа эсэхийг шалгасан\[cite: 1].



\## Playwright болон Selenium-ийн ялгааны талаарх миний ажиглалт

Өмнө нь ашиглаж байсан Selenium болон энэ удаа судалсан Playwright хоёулаа Apache 2.0 нээлттэй эхийн лицензтэй тул ямар нэгэн төлбөргүйгээр чөлөөтэй ашиглах боломжтой байна\[cite: 1]. Гэхдээ код бичих явцад Playwright нь хөгжүүлэгчид хамаагүй ээлтэй, орчин үеийн олон давуу талтай нь шууд анзаарагдсан\[cite: 1]. Тухайлбал, Selenium шиг элемент гарч ирэхийг хүлээж гараар explicit wait бичих шаардлагагүй, өөрөө автоматаар хүлээдэг (auto-wait) системтэй учраас тестүүд илүү тогтвортой ажиллаж байна\[cite: 1]. Мөн хөтөч тус бүрд драйвер гараар татаж суулгах шаардлагагүйгээр ганцхан команмаар бүх зүйл бэлэн болж байгаа нь цаг хэмнэсэн маш гоё шийдэл юм\[cite: 1]. Туршилтын явцад ямар нэгэн алдаа гарахад Trace Viewer ашиглан алхам алхмаар нь бичлэг хэлбэрээр эсвэл DOM snapshot хараад дебаг хийхэд тун амархан санагдлаа\[cite: 1]. Ерөнхийдөө хурд, тохиргоо болон хэрэглэхэд хялбар байдлаараа Playwright илүү давуу санагдсан тул цаашид туршиж ашиглахад урамтай санагдсан\[cite: 1].
